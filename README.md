# Python Logical Proposition Analyzer and Classifier

A Python-based application that analyzes compound logical propositions and generates truth tables. The project translates mathematical logic into executable code using fundamental programming structures and evaluates binary truth-value combinations.

Developed as an academic programming project, it focuses on logical reasoning, structured problem-solving, and implementing mathematical rules in Python.

## Features

- Analysis of compound logical propositions.
- Truth-table generation using binary truth values (`1` and `0`).
- Evaluation of logical combinations.
- Interactive menu for working with the application.
- Use of functions, docstrings, conditionals, loops, and lists.

## Tech Stack

- **Language:** Python
- **Programming concepts:** Functions, docstrings, conditionals, iterative loops, lists, logical evaluation

## Getting Started

### Prerequisites

- Python 3

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/lucianacalisaya/python-logical-proposition-analyzer-and-classifier.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-logical-proposition-analyzer-and-classifier
   ```

3. Run the application:

   ```bash
   python trabajo-integrador-calisaya-matematica.py
   ```

   Depending on your installation, you may need to use `python3` instead of `python`.
